# Feedback and licensing

[简体中文](#zh-cn) · [Product overview](../README.md)

Choose **Bug report** to report a problem or **Feature request** to make a suggestion. [Open the issue chooser](https://github.com/Auspicore/ELab/issues/new/choose)

- **Bug reports.** Include the ELab version, operating system and architecture, the steps to reproduce the problem, and the expected and actual results.
- **Feature requests.** Describe the task you are trying to complete and the result you would like to achieve.

Share a screenshot or a minimal example only after removing confidential project details and personal information. Public Issues are intended for non-sensitive reports.

The contact for partnerships, commercial licensing, and educational licensing is pending. See the [FAQ](faq.md) for evaluation information.

## 反馈与授权

[产品介绍](../README.zh-CN.md)

遇到问题请选择 **Bug report / 问题反馈**，有改进建议请选择 **Feature request / 功能建议**。[选择反馈类型](https://github.com/Auspicore/ELab/issues/new/choose)

- **问题反馈。** 请提供 ELab 版本、操作系统和架构、复现步骤、预期结果与实际结果。
- **功能建议。** 请描述希望完成的任务，以及你希望达到的结果。

提交截图或最小复现样例前，请移除工程中的保密内容和个人信息。公开 Issues 适用于非敏感问题。

商业合作、商业授权及院校授权的联系方式待公布。体验信息见[常见问题](faq.md#zh-cn)。
