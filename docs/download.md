# Download ELab

[简体中文](#zh-cn) · [Product overview](../README.md)

There are currently no public downloads for Windows, Linux, or macOS.

- **Stable** releases are intended for regular use on the operating systems and architectures listed in the release notes.
- **Preview** releases are intended for compatibility testing. Review the known limitations before downloading.

When releases are available, this page will point to the latest Stable release and the version history on GitHub Releases. Each downloadable package will list its platform, architecture, supported system versions, prerequisites, file size, publication date, and checksum.

Choose x64 or ARM64 to match your system. On macOS, choose the Intel build for an Intel Mac or the ARM64 build for Apple Silicon. To download ELab, select an application package listed under **Assets** for your platform and architecture. See the [installation and checksum guide](installation.md).

## 下载 ELab

[产品介绍](../README.zh-CN.md)

目前 Windows、Linux 和 macOS 均暂无公开下载。

- **稳定版（Stable）** 适用于发行说明列出的操作系统和架构，供日常使用。
- **公开测试版（Preview）** 用于兼容性测试。下载前请阅读已知限制。

发布后，本页将提供 GitHub Releases 最新稳定版和历史版本入口。每个下载项将标明平台、架构、适用系统版本、运行条件、文件大小、发布日期和校验值。

请选择与系统匹配的 x64 或 ARM64 文件。Intel Mac 请选择 x64 版，搭载 Apple 芯片的 Mac 请选择 ARM64 版。在 **Assets** 中找到对应平台和架构的应用程序包。详见[安装及校验指南](installation.md#zh-cn)。
