## Desktop package status

- **Stable** releases are intended for regular use on the operating systems and architectures listed in the release notes.
- **Preview** releases are intended for compatibility testing. Review the known limitations before downloading.

Each desktop release will list the package format, tested system versions, prerequisites, file size, publication date, and checksum.

Choose x64 or ARM64 to match your system. On macOS, choose x64 for an Intel Mac or ARM64 for Apple Silicon. Once your platform has an application package, find it under **Assets** in its desktop release. See the [installation and checksum guide](installation.md).
