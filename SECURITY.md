# Reporting a vulnerability

[简体中文](#security-zh-cn)

Sign in to GitHub and use **Report a vulnerability** on the ELab security advisories page to contact the maintainers privately. Include the ELab version if available, the operating system and architecture, the conditions where you observed the issue, and its impact. Remove credentials, personal information, and confidential project data from attachments. [ELab security advisories](https://github.com/Auspicore/ELab/security/advisories)

For ordinary bugs and feature suggestions, use the [feedback guide](docs/feedback.md). Public desktop releases are in preparation.

<a name="security-zh-cn"></a>
## 报告安全漏洞

登录 GitHub，在 ELab 安全公告页选择 **Report a vulnerability**，私密联系维护者。请提供可确认的 ELab 版本、操作系统及架构、问题出现的条件和影响。提交附件前，请移除凭据、个人信息和保密工程数据。[ELab 安全公告](https://github.com/Auspicore/ELab/security/advisories)

普通问题和功能建议见[反馈指南](docs/feedback.md#zh-cn)。公开桌面版仍在准备。
